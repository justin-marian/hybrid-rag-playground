## How to read this report

- Start with retrieval metrics before judging generated answers.
- If Recall@10 is low, the retriever is missing relevant documents.
- If MRR is low, useful evidence exists but appears too late.
- If nDCG@10 is low, ranking quality needs tuning.
- If RAG answers look unsupported, inspect the saved prompt and retrieved chunk IDs.
